# Рабочий стол

Все запросы требуют Authorization: Bearer TOKEN. Эти роуты предназначены для показателей и коротких списков первого экрана; полные списки остаются в GET /tasks и GET /leads.

## Роуты

~~~http
GET /workspace/tasks
GET /workspace/leads
~~~

Общие параметры:

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| scope | mine | mine — свои записи; team — вся команда, только admin/manager |
| ownerId | текущий пользователь | Конкретный сотрудник; выбирать другого может только admin/manager |
| timezone | Europe/Moscow | Часовой пояс IANA |
| limit | 6 | Размер каждого короткого списка, от 1 до 20 |

scope=team нельзя сочетать с ownerId. Неуказанный ownerId никогда не означает всю команду по умолчанию. Обычный пользователь получает 403 при запросе команды или другого сотрудника.

Ответы содержат generatedAt в UTC, timezone, localDate, фактическую scope (mine/team/owner), ownerId и limit.

## Задачи

GET /workspace/tasks возвращает overdue, today, upcoming. В каждом блоке:

~~~json
{"total": 27, "hasMore": true, "items": []}
~~~

total считается по всей выборке, а items ограничены limit и отсортированы по dueAt, затем _id. В реальном ответе items содержит до limit задач. Компания и лид в задаче представлены краткими объектами (_id/name и _id/title); внутренние поля связанных сущностей не выдаются.

Все корзины содержат только открытые неудалённые задачи. overdue — dueAt раньше generatedAt; today — текущий календарный день в timezone; upcoming — начиная со следующего дня. Просроченная сегодня задача входит в обе первые корзины, поэтому их счётчики нельзя складывать как количество уникальных задач.

Три корзины рассчитываются одним MongoDB facet с общей границей времени. Сохраняются проверки доступа к связанным лидам и сделкам, включая исторические задачи.

## Новые лиды

GET /workspace/leads возвращает newLeads с total, hasMore и items. Новыми считаются лиды активных этапов kind=new, не по названию этапа. Лиды отсортированы по createdAt и _id по убыванию. Используется обычная публичная сериализация лидов, без внутренних данных конвертации.

## Переходы в полные списки

~~~http
GET /workspace/tasks?ownerId=USER_ID
GET /tasks?bucket=overdue&ownerId=USER_ID&timezone=Europe/Moscow

GET /workspace/leads?scope=team
GET /leads?status=new
~~~

Для команды в обычных списках ownerId не передаётся. Их действующая серверная проверка прав не менялась.

## Ошибки

Некорректные параметры возвращают 422, отсутствие авторизации — 401, запрещённая область — 403. Сбой MongoDB возвращает ошибку сервера, а не успешный ответ с нулевыми счётчиками. Ответы помечены Cache-Control: no-store.
